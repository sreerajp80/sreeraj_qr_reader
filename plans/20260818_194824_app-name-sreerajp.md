# Make the app name "SreerajP QR Reader" everywhere

**Status:** completed

## The issue

The app name is written two different ways in the repository:

- `assets/config/app_config.json` says **SreerajP QR Reader** (no space after "Sreeraj").
- Almost everything else says **Sreeraj P QR Reader** (with a space).

The user wants one name: **SreerajP QR Reader**.

Note: the *person's* name stays **Sreeraj P**. Only the *app* name changes.
So the author field, the copyright line on the About screen, and the vCard
test fixture are left alone.

| `lib/core/config/app_config.dart` | fallback `appName:` → `SreerajP QR Reader` |

## The fix

1. Replace the exact text `Sreeraj P QR Reader` with `SreerajP QR Reader` in the
   files listed above. The search is for the full app-name phrase, so a bare
   `Sreeraj P` (the person) is never touched.
2. Run `flutter gen-l10n` to rebuild the generated localization files.
3. Run `dart format .`, `flutter analyze` (must be clean) and `flutter test`.
4. Write the change log to `change_log/`.

## Risk

Low. The name is a display string only. The package id `in.sreeraj.qr_reader`,
the Flutter project name `sreeraj_qr_reader`, and the signing setup do not change,
so this is not a new app for the Play Store — only the shown label changes.

One behaviour note: the JSON export file will now carry
`"app": "SreerajP QR Reader"`. The import path does not read that field
(it only reads `records`), so old export files still import fine.
