# Plan: Universal Encrypted QR Code Auto-Detection & Manual Decryption

**Status:** Completed

## Overview
This plan adds universal encrypted QR code handling to `sreeraj_qr_reader`:
1. **Auto-Detection (Known Headers & Protocols):**
   - Optical Air-Gap Transfer (`textdataqr://`) generated by `SreerajP_TextApp` (AirQR): AES-256-GCM + PBKDF2-HMAC-SHA256 (200,000 iterations) + Gzip decompression + payload envelope extraction.
   - StegoQR (`STEGOQR:v1:` and `--STEGOQR--`): AES-256-CBC + PBKDF2-HMAC-SHA256 (10,000 iterations).
   - Standard JSON Crypto Envelopes: JSON containers containing `iv`, `salt`, `ciphertext` / `data`, `tag`.
   - PGP / ASCII-armored headers (`-----BEGIN PGP MESSAGE-----`).
2. **Universal Manual Decrypt Tool:**
   - Adds a "Decrypt Payload" action button on the scan result screen for any scanned text or unknown ciphertext.
   - Displays a clean dialog with cipher selection (AES-GCM, AES-CBC, raw passphrase, or PBKDF2), optional salt/IV inputs, and instant decryption preview.

## Files to Create / Modify

### 1. `lib/models/encrypted_payload_data.dart` (New Model)
- Represents auto-detected or manually decrypted payload states, container type (`airQr`, `stegoQr`, `jsonEnvelope`, `pgp`, `rawCipher`), metadata (file name, MIME, kind), unlocked status, decrypted text, and error states.

### 2. `lib/services/encrypted_payload_service.dart` (New Service)
- **AirQR decoding & decryption:**
  - Parses `textdataqr://m` (manifest) and `textdataqr://f` (data frames).
  - Derives AES-256 key from session code (e.g. `ABC-DEF`) and salt via PBKDF2-HMAC-SHA256 (200k iterations).
  - Unseals AES-256-GCM (12-byte nonce), uncompresses Gzip, verifies SHA-256 digest, and extracts the envelope (`content`, `name`, `mime`, `kind`).
- **JSON crypto container decryption:**
  - Auto-extracts `iv`, `salt`, `ciphertext`, and `tag`.
  - Supports AES-GCM and AES-CBC.
- **Generic/manual cipher decryption:**
  - Configurable decryption for AES-256-GCM, AES-256-CBC, and AES-128 with custom/auto PBKDF2 iterations or direct keys.

### 3. `lib/providers/scan_provider.dart` (Modify Provider)
- Integrates `EncryptedPayloadService`.
- Detects encrypted container types during `setScanResult`.
- Exposes `encryptedPayloadData` and methods `decryptAirQrPayload(String code)`, `decryptPayload(String passphrase, ...)`.

### 4. `lib/screens/result_screen.dart` (Modify Screen)
- Updates Stego / Encrypted payload card to support AirQR session codes and JSON crypto containers.
- Adds "Decrypt Payload" action button for any text payload.
- Adds manual decryption dialog with cipher mode selector and key input.

### 5. `lib/l10n/app_en.arb` (Modify Localization)
- Adds user-visible localized strings and `@key` descriptions for AirQR, JSON containers, manual decryption dialog, cipher options, and feedback messages.

### 6. `test/services/encrypted_payload_service_test.dart` (New Unit Tests)
- Tests AirQR parsing and AES-GCM decryption with vectors matching `SreerajP_TextApp`.
- Tests JSON crypto container parsing and AES-CBC / AES-GCM decryption.
- Tests manual decryption of raw ciphertexts.
- Tests error handling on invalid keys or corrupted data.
