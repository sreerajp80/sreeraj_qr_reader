# Change Log: StegoQR Biometric-Locked Encrypted QR Reader

**Date:** 2026-07-31
**Plan:** [plans/20260731_070000_stego_qr_reader_biometric_encrypted.md](../plans/20260731_070000_stego_qr_reader_biometric_encrypted.md)

## Summary of Changes
Implemented **Feature 3.1: StegoQR — Biometric-Locked Encrypted Steganographic QR System (Reader Engine)** in Sreeraj QR Reader. The app now detects StegoQR header markers embedded in scanned barcode payloads, presents the public decoy content, and allows the user to securely authenticate via biometrics (`local_auth`) or passphrase to derive a key (PBKDF2) and decrypt the secret payload (AES-256).

### 1. Dependencies & Manifests
- `pubspec.yaml`: Added `local_auth: ^2.3.0`, `encrypt: ^5.0.3`, and `pointycastle: ^3.9.1`.
- `MainActivity.kt`: Changed base activity class to `FlutterFragmentActivity` for native biometric modal support.
- `AndroidManifest.xml`: Declared `android.permission.USE_BIOMETRIC`.

### 2. Models & Services
- `lib/models/stego_qr_data.dart`: Created immutable model for StegoQR payloads.
- `lib/services/stego_qr_service.dart`: Created service for header detection (`STEGOQR:v1:` and `--STEGOQR--`), format parsing, PBKDF2 key derivation, and AES-256 CBC decryption.
- `lib/services/biometric_service.dart`: Created wrapper for `LocalAuthentication` handling hardware checks and biometric prompt execution.

### 3. State Management & UI
- `lib/providers/scan_provider.dart`: Integrated `StegoQrService` and `BiometricService`. Extracted decoy payload for safety checks while managing stego unlock lifecycle.
- `lib/screens/result_screen.dart`: Added StegoQR Card UI featuring public decoy text view, Biometric Unlock button, Passphrase dialog fallback, and a secure decrypted payload view card with copy and share capabilities.

### 4. Tests
- `test/services/stego_qr_service_test.dart`: Added unit tests for StegoQR detection, format parsing, encryption/decryption roundtrips, and invalid passphrase handling.
- `test/providers/scan_provider_stego_test.dart`: Added unit tests for `ScanProvider` StegoQR payload processing, URL check routing, and unlock operations.
