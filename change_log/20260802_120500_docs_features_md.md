# Added docs/features.md

Implements plan: `plans/20260802_120000_docs_features_md.md`

## What changed

Added a new file, `docs/features.md`, that lists every feature of the app in
one place: core scanning, the 6-layer URL safety check, the zero-trust link
preview, Quishing Guard tamper detection, StegoQR hidden content, smart
payload actions (Wi-Fi, contacts, location, calendar, payment, 2FA), scan
history, AirQR optical transfer, AR CodeVision, theming/settings, and
security/privacy behaviour. It also has a short "Key technical facts" table
(SDK versions, state management, storage, dependencies).

No app code was changed. This is documentation only.

## Why

The user wants to hand this file to another AI assistant working on a
different app, so that assistant can check what this app already does
before it builds an overlapping feature elsewhere. The content was built by
reading the app source code, `pubspec.yaml`, and every file in
`change_log/`, since the older docs (`docs/architecture.md`,
`docs/security.md`, `docs/project_structure.md`) describe an outdated,
simpler version of the app.
